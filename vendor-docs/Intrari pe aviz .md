WinMENTOR
Opţiunea de import este în MENTOR > Interne > Import date din alte aplicaţii > Avize
 cod extern/intern/fiscal partener –
se reglează prin constanta: „Cod
CodFurnizor=C000020 pentru identificare PARTENER”
vezi Constante generale > Import
date din alte aplicaţii.
 cod extern/intern articol – se
reglează prin constanta: „Cod
Item_2=A0000013880;BUC;1.2;21850;P8201 pentru identificare ARTICOLE”
vezi Constante generale >
Import date din alte aplicaţii;
WinMENTOR;
În cazul utilizării de noi articole, se va utiliza fişierul „Articole.txt” pentru descrierea lor.
